## 0. 發布前必讀：合規與平台規範

CFD 是高風險槓桿商品。廣告審查、平台審核和監管機構都會盯這一類內容，以下每一條都要做到：

| 項目 | 做法 |
|---|---|
| **不承諾收益** | 不說「穩賺」「翻倍」「保本」「月入 X 萬」。只說「工具能做什麼」，不說「你會賺多少」。 |
| **風險提示（每支都要）** | 口播最後一句＋畫面底部常駐字卡：「CFD 具槓桿風險，可能損失全部本金。本內容僅供教育，非投資建議。」 |
| **AI 標示** | Meta / TikTok / YouTube 都要求標示寫實的 AI 生成內容。發文時開啟平台的「AI 生成」標籤，片頭角落放「AI 虛擬主播」浮水印。 |
| **AI 主播肖像** | 只用 AI 影片平台的授權虛擬人像或自建分身。**不可**用真實名人、財經 KOL 的臉或聲音。 |
| **績效數字** | 引用 EA 績效時，必須同時寫出：期間、起始資金、手數、**最大淨值回撤**，並加註「過去績效不代表未來」。不能只秀報酬率。 |
| **目標市場法規** | CFD 的銷售與推廣規範依地區而異（例如部分地區限制散戶參與，或把「推薦交易策略」視為投顧業務）。投放廣告前請先找當地法務確認；Meta 對金融服務廣告在部分國家也要求廣告主驗證。 |
| **不導向特定券商開戶** | 除非你持有相關牌照或合作合約已經法務審核，否則不在影片中放券商開戶連結。 |

## 2. 腳本

格式說明：
- **口播**：AI 主播念的內容，已控制在每秒約 4–5 字。
- **畫面**：剪輯時疊加的字卡、圖表、B-roll。
- **貼文**：發布時的文案與 hashtag。

> 範例中的金價用「假設 3,800 美元」示範。拍攝前請改成當週實際價格附近的整數，或保留「假設」二字。

- 導流版：「想看 EA 的實際觀摩帳號，私訊我們。」（不在影片中直接放開戶連結）

**固定風險字卡（全片底部常駐，字級不小於字幕的 60%）**：
> CFD 具高槓桿與高波動風險，可能損失全部本金。本內容僅供教育參考，不構成投資建議。過去績效不代表未來收益。

## 4. AI 主播製作流程

1. **主播設定**：選一個固定的授權虛擬人像（HeyGen、Synthesia、D-ID、Hedra 等平台皆可），整個系列統一同一位主播、同一套服裝與背景，建立辨識度。建議風格：深色商務背景＋品牌金色 `#c9a227` 點綴。
2. **聲音**：繁體中文、台灣或中性口音、語速偏慢（約 4–5 字/秒）。數字較多的段落可在腳本內斷句（逗號），讓 TTS 停頓自然。
3. **產出**：每支腳本的「口播」欄位直接貼進平台生成主播影片。
4. **剪輯**（CapCut / Premiere）：依「畫面」欄加字卡與圖表。圖表建議用 MT5 實際畫面錄影或簡潔動畫，**不用來源不明的收益截圖**。
5. **字幕**：燒錄繁中字幕（多數人靜音瀏覽），重點數字放大加色。
6. **檢查**：發布前逐條對照第 0 節合規表。
7. **發布**：開啟 AI 標籤。同一支影片可同步發 FB / IG / YouTube Shorts / TikTok，但文案依平台微調。

## 5. 成效追蹤建議
